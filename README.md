# Roofing Job Checker

A simple, static UK consumer-advice website to help people understand a roofing repair quote before committing to work or paying money.

## Purpose

A clear invoice or receipt does not necessarily explain the scope of work. This project encourages people to request a written description of every task, a cost breakdown, exclusions, scaffolding and waste costs, payment stages, dates, and details of guarantees before agreeing where circumstances allow.

## Features

- Pre-agreement checklist for roofing repair quotes
- Plain-language guidance about urgency and pressure to pay
- Reminders to clarify scaffolding and bundled jobs
- Interactive checklist showing items still to clarify
- Local-only message builder to request a written breakdown
- Links to Citizens Advice consumer guidance
- No accounts, analytics, backend, or external JavaScript libraries

## GitHub Pages

Designed to be hosted as a static GitHub Pages site from the root of the `main` branch.

## Disclaimer

General information only, not legal advice or an assessment of any contractor. It cannot verify contractor competence or guarantee an outcome. Advice and options depend on the facts and circumstances. Urgent safety issues may need prompt action.
